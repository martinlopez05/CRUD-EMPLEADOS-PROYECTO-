# CRUD de Empleados - Java Swing y Maven

Este proyecto es una aplicación de escritorio desarrollada con **Java Swing** y **Maven**. El objetivo de la aplicación es gestionar empleados y sus respectivos departamentos dentro de una empresa. Permite realizar operaciones CRUD (Crear, Leer, Actualizar, Eliminar) tanto para los empleados como para los departamentos.

## Descripción

Este sistema permite a los usuarios gestionar los empleados de una empresa, asociándolos a diferentes departamentos. Las principales funcionalidades incluyen:

- **Alta de empleados:** Registrar nuevos empleados con su nombre, apellido, y asignación a un departamento.
- **Listado de empleados:** Ver los empleados registrados en la base de datos y los departamentos a los que pertenecen.
- **Edición de empleados:** Modificar la información de un empleado, incluyendo su departamento.
- **Eliminación de empleados:** Eliminar empleados del sistema.
- **Alta de departamentos:** Crear nuevos departamentos dentro de la empresa.
- **Listado de departamentos:** Ver todos los departamentos existentes en la empresa.

## Características

- **Interfaz gráfica de usuario (GUI):** Construida con Java Swing para una experiencia de usuario sencilla y amigable.
- **Persistencia de datos:** Utiliza una base de datos para almacenar la información de empleados y departamentos.
- **Modelo MVC:** Implementación del patrón de diseño Modelo-Vista-Controlador para una mejor organización y mantenibilidad del código.
- **Maven:** Utiliza Maven para la gestión de dependencias y construcción del proyecto.

## Tecnologías Utilizadas

- **Java Swing:** Para la interfaz gráfica de usuario (GUI).
- **Maven:** Para la gestión de dependencias y construcción del proyecto.
- **MySQL (o base de datos relacional):** Para almacenar la información de empleados y departamentos.
- **JDBC:** Para la conexión entre la aplicación y la base de datos.
